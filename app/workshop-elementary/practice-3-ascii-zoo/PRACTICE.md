# 🦁 실습 따라하기 — Ralph × Harness ASCII Zoo

이 문서를 처음부터 끝까지 그대로 따라하면 됩니다.
약 **20분** 걸려요.

---

## 🎯 이 실습에서 배울 것

두 가지를 직접 체험합니다:

1. **Ralph 패턴** — AI가 한 번에 못 하는 일을 **루프로 반복**해서
   완성하기. 세션이 끊겨도 작업이 이어지는 컨텍스트 유지.
2. **Harness(가드레일)** — AI가 폭주하지 않게 **도구 권한과 hook**으로
   안전하게 묶어두기.

목표: ASCII art 동물 10마리로 동물원을 만들기.

---

## 📦 0. 시작하기 전에

다음이 동작하는지 확인하세요.

```bash
claude --version
python3 --version
```

둘 다 버전이 나오면 OK.

---

## 📂 1. 프로젝트 폴더로 이동

압축을 풀고 폴더 안으로 들어갑니다.

```bash
unzip ascii-zoo.zip
cd ascii-zoo
```

폴더 구조 확인:

```bash
ls -a
```

이런 게 보여야 정상이에요:

```
.   ..   .claude   PROMPT.md   README.md   ZOO.md
animals   show_zoo.py   validate.py
```

`.claude/` 폴더가 가드레일(harness) 설정이고, 나머지가 Ralph가 작업할
프로젝트예요.

---

## 👀 2. 빈 동물원 한 번 보기

Ralph를 돌리기 전에 지금 상태를 확인해 봅시다.

```bash
python3 show_zoo.py
```

이런 화면이 보일 거예요:

**이게 시작점**입니다. 이 빈 동물원을 Ralph가 한 마리씩 채울 거예요.

## 📋 3. 어떤 가드레일이 걸려있는지 확인 (1분)

루프를 돌리기 전에 **무엇이 막혀있는지** 한 번 보세요.

```bash
cat .claude/settings.json
```

핵심만 읽어보면:

- ✅ **허용**: `animals/*.txt` 새로 쓰기, `validate.py` 실행, `show_zoo.py` 실행
- 🛑 **금지**: 이미 만든 동물 수정, `validate.py` 자체 수정, `rm`, `git`, `curl` 등

그리고 hook 두 개:

- `Stop` hook → 동물 10마리 다 안 채웠는데 멈추려고 하면 **차단**
- `PreToolUse` hook → 이미 있는 동물 파일 수정 시도하면 **차단**

> 💡 이게 **harness(가드레일)**의 핵심이에요. AI에게 "할 수 있는 것"과
> "절대 못 하는 것"을 미리 정해놓는 거죠.

---

## 🤖 4. Claude Code 시작 (10초)

같은 폴더에서:

```bash
claude
```

Claude 프롬프트가 뜨면 준비 완료. `.claude/settings.json`이 자동으로
적용돼서 가드레일이 활성화됩니다.

> ⚠️ **반드시** `ascii-zoo/` 폴더 안에서 `claude`를 실행해야 해요.
> 다른 폴더에서 시작하면 `.claude/settings.json`이 안 적용됩니다.

---

## 🌀 5. Ralph 루프 시작 (3분)

이제 **한 줄**로 루프를 시작합니다. Claude 프롬프트에 입력:

```
PROMPT.md를 읽고 따라줘.
ZOO.md를 보고 다음 동물 하나만 만든 다음 종료를 시도해.
모든 동물이 완성되면 <promise>ZOO_COMPLETE</promise>를 출력하고 종료해.
```

Claude가:
1. `PROMPT.md`를 읽음
2. `ZOO.md`를 봄 (지금은 다 비어있음)
3. 첫 번째 동물 `cat` 만들 차례임을 인식
4. `animals/cat.txt` 생성
5. `python validate.py animals/cat.txt`로 검증
6. `ZOO.md`에 `- cat ✓` 추가
7. `python show_zoo.py` 한 번 실행
8. **종료 시도** ← 여기서 마법이 일어남

### 🛑 여기서 Stop hook 발동!

8번에서 Claude가 종료하려고 하면, `.claude/hooks/check-zoo.sh`가
가로챕니다:

```
🛑 Stop blocked by Ralph loop guardrail.

Progress: 1 / 10 animals.
Still missing: dog fish turtle rabbit owl penguin elephant giraffe dragon

Re-reading your task. Continue with the NEXT missing animal.
```

이 메시지가 Claude에게 다시 입력으로 들어가서 **자동으로 다음 동물을
만들기 시작**합니다. 사용자가 아무것도 안 해도 루프가 돌아요.

> 🎯 **이게 Ralph 패턴의 핵심이에요.**
> "끝났다고 말해도 끝난 게 아닌" 구조로 작업을 강제 지속시켜요.

---

## 📺 6. 루프 관찰 (5~7분)

루프가 자동으로 돌아가는 동안 동물원이 자라는 걸 봅시다.

**다른 터미널을 하나 더 열어서** 같은 폴더로 가세요:

```bash
cd ascii-zoo
```

그리고 watch처럼 동물원을 계속 보고 싶으면:

```bash
# Linux/Mac에 watch 명령이 있으면
watch -n 3 python3 show_zoo.py

# 없으면 그냥 가끔 한 번씩 돌리기
python3 show_zoo.py
```

대략 1~2분에 동물 1마리씩 추가됩니다. 5분쯤 지나면 4~5마리,
10분쯤 지나면 거의 다 될 거예요.

> 💡 ZOO.md도 한 번 봐보세요. Ralph가 매 루프마다 여기에 진척을
> 기록하고 있어요. 이게 **컨텍스트 유지의 비결**입니다.
>
> ```bash
> cat ZOO.md
> ```

## ✂️ 7. 컨텍스트 유지 시연 — 일부러 끊어보기 (2분)

동물 4~5마리쯤 만들어졌을 때 **한 번 꺼봅시다**.

Claude가 돌아가는 터미널에서 `Ctrl+C` 두 번 눌러서 강제 종료.

```
^C^C
```

이제 한 번 확인:

```bash
ls animals/
cat ZOO.md
```

지금까지 만든 동물들과 진척이 **파일에 그대로 남아있어요**.

이제 다시 시작해 봅시다:

```bash
claude
```

Claude 프롬프트에:

```
PROMPT.md를 읽고 ZOO.md를 보고 이어서 작업해.
```

**관찰 포인트**: Claude가 ZOO.md를 읽고 "아, 5마리까지 했네요. 6번째인
owl부터 시작할게요" 같은 식으로 **이어서 작업**합니다.

> 🎯 **이게 컨텍스트 유지의 본질이에요.**
> AI의 "기억"이 아니라 **파일 시스템**이 메모리예요. 세션이 죽어도
> 파일이 살아있으면 작업은 이어집니다.

## 🚧 8. 가드레일 발동 시연 (선택, 2분)

루프가 돌아가는 도중에 가드레일이 어떻게 작동하는지 직접 시도해 볼
수 있어요. 다른 터미널에서:

### 시도 1: 이미 만든 동물 수정해보라고 시키기

새 Claude 세션 (다른 터미널)에서:

```bash
claude
```

```
animals/cat.txt를 더 귀엽게 다시 그려줘.
```

**관찰**: `protect-animals.sh` hook이 발동해서 차단합니다.

```
🛑 Blocked: 'animals/cat.txt' already exists and is finished.
Once an animal is in the zoo, it stays.
```

### 시도 2: 가드레일 자체를 약화시켜 보라고 시키기

```
validate.py에서 max height를 100으로 늘려줘.
```

**관찰**: `settings.json`의 `deny: ["Edit(validate.py)"]` 룰에 걸려서
거부됩니다.

> 💡 이게 **harness의 가치**예요. AI가 합리적인 이유로 시도하더라도,
> 미리 정해둔 규칙은 절대 못 어깁니다.

## 🎉 9. 완성 — Ralph가 스스로 종료 (자동)

10마리 다 만들어지면 Claude가 출력합니다:

<promise>ZOO_COMPLETE</promise>

이때는 `check-zoo.sh`가 "10/10이네, OK 종료해도 됨" 하고 통과시켜요.
루프가 깨끗하게 끝납니다.

마지막으로 한 번 더:

## 💭 10. 회고 (2분)

직접 답해보세요:

### 질문 1: 컨텍스트 유지

7단계에서 강제 종료했다가 다시 시작했을 때, Claude는 어떻게 어디까지
했는지 알았을까요?

힌트: AI 자체에는 메모리가 없어요. 그럼 어디에…?

### 질문 2: Stop hook의 역할

Stop hook이 없었다면 어떻게 됐을까요? 동물 1마리 만들고 끝나버리지
않았을까요?

### 질문 3: 가드레일의 트레이드오프

`Edit(animals/**)` deny 규칙은 "이미 만든 동물은 못 고친다"였어요.
이게 **너무 엄격할 때**는 언제일까요? 어떤 상황에서 풀어줘야 할까요?

## 🆘 막힐 때

### "max-iterations 초과" 라고 나옴
정상이에요. 한 번에 너무 오래 돌면 안전을 위해 멈춰요. 다시 `claude`로
시작해서 6단계의 프롬프트를 다시 입력하면 이어서 돕니다.

### Claude가 가드레일을 우회하려고 함
드물지만 일어나요. 예: `mv animals/cat.txt animals/cat_backup.txt`
같은 우회 시도. 그러면 deny 룰의 `Bash(mv:*)`에 걸려서 막힙니다.
못 막힌 우회가 있으면 진행자에게 알려주세요 — 가드레일을 보강할
좋은 학습 기회예요.

### `python3 show_zoo.py`가 깨져 보임
터미널 폭이 80자보다 좁으면 레이아웃이 깨져요. 터미널 창을
넓혀주세요.

### 동물이 너무 못생겨서 마음에 안 들음
**가드레일에 안 걸리고 통과했다면 그게 정답**이에요. Claude의 ASCII
art 솜씨에 일희일비하지 마세요. 핵심은 "루프가 돌아가는 것"입니다.

### 다 끝났는데 다시 처음부터 해보고 싶음
```bash
rm animals/*.txt
# ZOO.md의 Done 섹션도 비우기
```
이렇게 하고 다시 5단계부터.

## 🎓 한 줄 정리

> **Ralph = 시간**: 한 번에 못 해도 루프가 점진적으로 완성해요.
>
> **Harness = 신뢰**: 도구 권한과 hook으로 자율성을 안전하게 만들어요.
>
> 둘은 짝이에요. 루프만 있으면 폭주하고, 가드레일만 있으면 한 번에
> 다 해야 해요. **합쳐야 안전한 자동화가 됩니다.**

오늘 ASCII 동물원 10마리를 만들면서 그걸 직접 체험했어요. 🦁🐘🐧
