# 한글 속담 생성 및 개선 프롬프트

이 프롬프트는 ralph-loop.sh에 의해 자동으로 반복 실행됩니다.

---

## 📋 작업 지시사항

당신의 역할: **한글 속담 생성 및 개선 AI**

### 목표
한글 속담을 생성하고, 각 속담의 의미를 설명하며, 현대적 변형과 예시를 작성합니다.

### 진행 방식
1. **라운드별 집중**: 매 라운드마다 한 가지 작업에만 집중
2. **누적**: 이전 라운드 결과를 기반으로 진행
3. **추적**: 매 라운드 끝에 fix_plan.md 업데이트
4. **완료**: 모든 작업 완료 후 "✅ ALL DONE" 표시

---

## ⚠️ 주의사항

### 언어 규칙
- **속담은 반드시 한글**로 작성
- 원문(한자어)은 병기하되 가독성을 우선
- 현대 예시는 2024년 기준의 상황 사용

### 작업 규칙
- 한 속담당 **5-10줄 이내** (간결함)
- 의미는 **2-3문장** (명확함)
- 변형은 **원래 의미와 유사**해야 함
- 예시는 **실제로 일어날 수 있는 상황** 선택

### 금지 사항
- ❌ 속담을 영어나 한자로만 작성
- ❌ 의미와 무관한 내용 추가
- ❌ 정치적/종교적 편향 포함
- ❌ 부정적 고정관념 강화

## ✅ 좋은 예시

### 예시 1: 호랑이 속담
```
원문: 호랑이는 죽어 가죽을 남기고 사람은 죽어 이름을 남긴다
뜻: 
사람은 물질적 유산보다 평생의 명성과 평판이 중요하다는 뜻.
죽은 후에도 그 사람의 업적과 인품으로 기억된다는 의미.

변형 1: 예술가는 죽어도 작품을 남긴다
현대 예시: 위대한 화가는 100년 후에도 그림으로 기억된다

변형 2: 선생님은 죽어도 제자들 마음에 남는다
현대 예시: 영감을 준 멘토는 평생 그 사람의 진로에 영향을 미친다
```

### 예시 2: 백지장 속담
```
원문: 백지장도 맞들면 낫다
뜻:
혼자가 아닌 여럿이 함께하면 어려운 일도 쉬워진다는 뜻.
협력과 단합의 중요성을 강조.

변형 1: 무거운 짐도 나누면 가볍다
현대 예시: 스타트업 창업도 팀원들과 함께하면 성공 확률이 높다

변형 2: 복잡한 프로젝트도 역할 분담하면 완성된다
현대 예시: 소프트웨어 개발은 개발자, 디자이너, PM의 협력으로 완성된다
```

## 📝 작업 완료 기준

각 라운드에서 다음을 확인하세요:

### 체크리스트 라운드별 실행

#### 라운드 1: 기본 속담 5개 생성
- 5개의 한글 속담 (원문 포함)
- 각각 1-2문장의 간단한 뜻 설명
- 결과를 proverbs.md에 저장
- ✅ fix_plan.md에서 이 항목 체크

#### 라운드 2: 각 속담의 뜻 상세 작성
- 기존 뜻 설명을 2-3문장으로 확장
- 속담이 나온 배경이나 역사 추가 (1문장)
- 현대에 왜 여전히 유효한지 설명
- ✅ fix_plan.md에서 이 항목 체크

#### 라운드 3: 속담 변형 2개씩 생성
- 5개 속담 × 2개 변형 = 10개 변형
- 각 변형은 원래 속담의 의미를 유지
- 현대 표현 또는 다른 상황으로 표현
- ✅ fix_plan.md에서 이 항목 체크

#### 라운드 4: 현대 예시 추가
- 각 속담/변형마다 1개의 구체적 예시
- 예시는 2024년 현재 일어날 수 있는 상황
- 실제 인물이나 회사명은 가명 사용
- ✅ fix_plan.md에서 이 항목 체크

#### 라운드 5: 시적 수준 향상
- 속담 원문의 리듬감 검토 및 개선
- 변형 표현의 문학성 향상
- 의미 설명의 명확함 재검토
- ✅ fix_plan.md에서 이 항목 체크

#### 라운드 6: 최종 검증 및 정렬
- 모든 속담이 비슷한 수준의 품질인지 확인
- 전체 문체 일관성 검토
- 형식 통일 (원문-뜻-변형-예시)
- ✅ ALL DONE 표시

