## 💡 문제 해결

### 문제: ralph-loop.sh 실행 권한 없음
```bash
# 해결책
chmod +x ralph-loop.sh
./ralph-loop.sh
```

### 문제: Claude가 규칙을 잊음 (영어로 작성 등)
```markdown
# PROMPT.md에 표지판 추가
⚠️ **중요: 속담은 반드시 한글로 작성**

✅ 좋은 예: 호랑이는 죽어 가죽을...
❌ 나쁜 예: Tiger dies and leaves...
```

### 문제: 같은 작업 반복 (라운드 1이 계속됨)
```bash
# 해결책: 체크리스트 항목 명확히 분리
# PROMPT.md에서 각 라운드별로 다른 작업 명시
```

### 문제: 30회 다 돌았는데 완료 안 됨
```bash
# 해결책 1: 체크리스트 항목 줄이기 (6 → 3개)
# 해결책 2: 예시를 더 구체화 (better priming)
# 해결책 3: 더 저렴한 모델로 다시 실행 후 품질 향상
```
