# Practice 4 - 데모 스크립트

이 실습은 데모입니다. 직접 실행하지 않습니다.

## 개념 흐름

```bash
# 1단계: Claude 구현
$ claude -p "포켓몬 카드에 필터 기능 추가"
→ 코드 생성

# 2단계: Codex 검증
$ codex exec "위 코드를 보안/성능/에러처리 관점에서 리뷰"
→ 문제점 지적 + 패치 제안

# 3단계: Claude 수정
$ claude -p "위 리뷰를 반영해서 코드 수정"
→ 개선된 코드

# 4단계: 반복
```

## 주요 개념

- **Sycophancy**: AI가 자기 결과를 과하게 좋게 평가
- **Multi-model**: 다른 AI의 관점으로 검증
- **Review Gate**: 자동 품질 관리
