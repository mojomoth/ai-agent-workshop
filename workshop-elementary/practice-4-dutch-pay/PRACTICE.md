# 🍕 실습 따라하기 — Claude × Codex 더치페이 듀얼

이 문서를 처음부터 끝까지 그대로 따라하면 됩니다.
약 **25~30분** 걸려요.

---

## 📦 0. 시작하기 전에

다음 세 개가 터미널에서 동작하는지 먼저 확인해 주세요.

```bash
claude --version
node --version
python3 --version
```

세 개 다 버전이 나오면 OK. 하나라도 명령을 못 찾으면 진행자에게 도움을 요청하세요.

> 💡 Claude Code 안에서 Codex 플러그인이 이미 설정되어 있다고 가정합니다.
> 만약 `/codex:setup` 명령이 안 먹으면 진행자를 부르세요.

---

## 📂 1. 프로젝트 폴더로 이동

압축을 풀고 폴더 안으로 들어갑니다.

```bash
unzip dutch-pay.zip
cd dutch-pay
```

폴더 구조 한 번 확인:

```bash
ls
```

이런 게 보여야 정상이에요:

```
QUICKSTART.md  README.md  break_it.py  docs/  reviews/  src/  tests/
```

`src/dutch_pay.py`를 열어보면 **거의 비어있어요**. 우리가 채울 거예요.

---

## 🤖 2. Claude Code 시작

같은 폴더에서:

```bash
claude
```

Claude 프롬프트가 뜨면 준비 완료. 이제부터 명령은 **Claude 안에 입력**합니다.

> ⚠️ 별도 표시가 없으면 모든 명령은 Claude 프롬프트 안에서 실행하세요.
> 터미널 명령(`bash`, `python3` 같은 거)은 따로 표시할게요.

---

## 🎬 3. 1막 — Claude한테 코드 짜달라고 시키기 (8분)

Claude 프롬프트에 이걸 그대로 입력하세요:

```
docs/SPEC.md를 읽고 src/dutch_pay.py를 구현해줘.
tests/test_dutch_pay.py도 작성해서 pytest로 통과시켜.
```

**기다리세요.** Claude가:

1. 명세 파일을 읽고
2. 코드를 짜고
3. 테스트도 짜고
4. pytest 돌려서 통과시키고
5. "잘 동작합니다 ✓" 같은 메시지로 마무리

보통 5~7분 걸려요.

> 💡 끝나면 잠깐 멈춰서 Claude가 뭐라고 자평하는지 읽어보세요.
> "엣지 케이스도 잘 처리했고...", "안정적이고..." 같은 말이 나올 거예요.

### ❓ 만약 Claude가 너무 잘 짜는 것 같으면

Claude가 가끔 처음부터 `Decimal` 같은 걸 쓰거나 너무 방어적으로 짤 수 있어요. 그러면 한 번 더 입력:

```
SPEC.md에 명시된 대로만 단순하게 구현해줘. 추가 검증이나
Decimal 같은 건 명세에 없으니 빼고 가장 단순하게 짜줘.
```

이렇게 하면 함정에 자연스럽게 빠집니다.

## 🥊 4. 1막 검증 — 일상 시나리오로 깨뜨려보기 (1분)

Claude는 그대로 두고, **새 터미널을 하나 더 엽니다.**

```bash
cd dutch-pay
python3 break_it.py
```

7가지 식당 시나리오가 줄줄이 돌아갈 거예요. 이런 게 보일 가능성이 높아요:

```
🥢  시나리오 2: 분식집 1,000원 떡볶이를 3명이
   각자 낼 금액: [333.3333333333333, 333.3333333333333, 333.3333333333333]
   💥 부동소수점 사용 중!

🤔  시나리오 3: '아무도 안 왔어' (인원 0명)
   💥 ZeroDivisionError — 사용자에게 친절한 메시지 없음
```

> 💥 **체감 포인트**: Claude는 "잘 됐다"고 했는데, 실제로는 송금도
> 못 할 코드가 나왔어요. 결함이 몇 개 보이는지 세어보세요.

### ✅ 체크리스트

발견된 결함에 표시해 보세요:

- [ ] 시나리오 2: 부동소수점 (333.3333...)
- [ ] 시나리오 3: 0명 입력 시 에러
- [ ] 시나리오 4: 음수 금액 그대로 통과
- [ ] 시나리오 5: 부가세/팁 순서 모호
- [ ] 시나리오 6: split_with_exclusions에서 합 안 맞음
- [ ] 시나리오 7: format_won 음수 표시 어색

## 🪞 5. 2막 — Claude한테 자기 코드 리뷰시키기 (3분)

Claude 세션으로 돌아가서 입력:

```
방금 만든 dutch_pay.py를 다시 한 번 검토해줘.
혹시 놓친 케이스나 버그 있을까?
```

Claude가 자기 코드를 리뷰합니다. 보통 이런 식으로 답이 나와요:

- "전반적으로 잘 동작합니다"
- "타입 힌트를 추가하면 좋겠네요"
- "엣지 케이스 보강을 고려해보세요"

방금 4단계에서 본 **진짜 큰 결함들은 잘 못 짚어요**.

> 💡 **이게 sycophancy(자기 코드 좋게 보기) 현상이에요.**
> 같은 모델은 같은 가정 안에서 보기 때문에 사각지대도 같이 가져요.

### 📝 결과 저장

Claude의 응답을 복사해서 `reviews/01-claude-self-review.md` 파일을 열어 "Claude 응답" 섹션에 붙여넣으세요. 나중에 비교용입니다.

## 🔍 6. 3막 — Codex 일반 리뷰 (4분)

이제 다른 모델을 데려옵니다. Claude 세션에서 그대로:

```
/codex:review src/dutch_pay.py
```

Codex가 더 객관적으로 봐줘요. 30초~1분 정도 기다리세요.

이번엔 자기 리뷰보다는 좀 더 잡힐 거예요:

- "0명 처리 로직이 누락됐습니다"
- "부동소수점 정밀도 문제가 있을 수 있습니다"
- "타입 검증이 없습니다"

근데 아직 **모든 걸 잡진 못해요**. 일반 리뷰는 "예의 바른" 톤이에요.

### 📝 결과 저장

응답을 `reviews/02-codex-review.md`에 붙여넣으세요.

## ⚔️ 7. 4막 — Codex 적대적 리뷰 ⭐ (5분, 클라이맥스)

이게 **실습의 핵심**이에요. Claude 세션에서:

```
/codex:review --adversarial src/dutch_pay.py
```

`--adversarial` 한 단어가 추가됐을 뿐인데 결과가 완전히 달라요.
Codex가 **"이 코드를 어떻게 깨뜨릴까?"** 시점으로 봐줍니다.

이런 게 쏟아질 거예요:

- "1원이 사라지는 반올림 버그가 있습니다"
- "음수 금액이 그대로 처리됩니다"
- "부가세/팁 적용 순서가 모호한 명세를 검증 없이 한 가지로 결정"
- "split_with_exclusions에서 분배 합이 원금과 일치하지 않을 수 있음"
- "format_won이 음수와 부동소수점에서 어색한 결과"

> 💥 **체감 포인트**: 일반 리뷰는 "잘 짰나요?"를 묻고,
> 적대적 리뷰는 "어떻게 깨뜨릴까?"를 물어요. 같은 모델, 다른 질문.

### 📝 결과 저장

응답을 `reviews/03-codex-adversarial.md`에 붙여넣으세요.

## 🛠️ 8. 5막 — Codex한테 수정 시키기 (4분)

이제 발견한 이슈들을 Codex가 직접 고치게 합니다. Claude 세션에서:

```
/codex:rescue src/dutch_pay.py의 적대적 리뷰에서 발견된 모든
이슈를 수정해줘. 기존 테스트는 깨지지 않게 유지하고 새 케이스용
테스트도 추가해.
```

**여기가 정말 멋진 부분**이에요:

- 한 터미널 안에서 Codex가 background로 돌아가면서 코드를 고침
- Claude 세션은 살아있고 진행 상황이 그대로 보임
- 두 모델이 **한 화면에서 협업**합니다

3~5분 정도 걸려요. 끝나면 Claude가 "Codex가 수정 완료했습니다" 비슷한 메시지를 줍니다.

## 🆘 막힐 때

### Claude가 8단계(1막)에서 너무 오래 걸림

정상이에요. 7~8분까지는 기다려주세요. 10분 넘게 멈춰있으면 Ctrl+C 후 재시도.

### `/codex:review` 명령이 "Unknown command"라고 나옴

플러그인이 활성화 안 됐어요. Claude Code를 종료하고 다시 시작한 다음 진행자를 부르세요.

### `python3 break_it.py`가 ImportError를 냄

1막이 아직 안 끝났거나 코드가 비어있어요. 1막을 마저 진행하세요.

### Codex 응답이 이상하게 짧음

가끔 그래요. 한 번 더 시도하거나, 명령에 더 구체적인 지시 추가:

```
/codex:review --adversarial src/dutch_pay.py
모든 함수에 대해 깨질 수 있는 케이스를 찾아줘.
```

### 시간이 부족해서 1막을 건너뛰고 싶을 때

백업 모드:

```bash
cp docs/flawed_reference.py src/dutch_pay.py
```

이러면 4단계(`break_it.py`)로 바로 갈 수 있어요. 단, Codex 부분은 그대로 진행합니다.
