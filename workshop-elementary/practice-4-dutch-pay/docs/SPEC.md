# 🍕 더치페이 계산기 — 명세

친구들이 식당에서 같이 밥 먹고 더치페이할 때 쓰는 작은 계산기.

## 시나리오

> 4명이서 치킨집 갔다. 총 메뉴 가격 40,000원.
> 부가세 10% 별도. 팁 5% 주기로 함.
> 한 명당 얼마씩 내야 할까?

## 만들어야 할 함수들

### 1. `split_evenly(amount, people)` — 똑같이 나누기

총 금액을 인원수로 나눈다.

```python
split_evenly(40000, 4)
# → [10000, 10000, 10000, 10000]
```

### 2. `add_tax(amount, tax_rate=0.1)` — 부가세 추가

부가세를 더한 최종 금액 반환.

```python
add_tax(40000)        # → 44000
add_tax(40000, 0.1)   # → 44000
```

### 3. `add_tip(amount, tip_rate=0.05)` — 팁 추가

팁을 더한 금액 반환.

```python
add_tip(40000)         # → 42000
add_tip(40000, 0.10)   # → 44000
```

### 4. `calculate_total(menu_total, tax_rate=0.1, tip_rate=0.05)` — 최종 합계

부가세와 팁을 모두 적용한 최종 금액.

```python
calculate_total(40000, 0.1, 0.05)
# → 46000  (40000 + 4000 부가세 + 2000 팁)
```

### 5. `split_with_exclusions(amount, people, exclusions=None)` — 일부 빠지는 케이스

```
> 민수는 술 안 마셔서 술값 5,000원은 빼고 계산하자.
```

```python
# 4명, 총 40000원, 민수(인덱스 0)는 5000원 빠짐
split_with_exclusions(40000, 4, exclusions={0: 5000})
# 민수: (40000 - 5000) / 4 = 8750
# 나머지 3명: 8750 + 5000/3 ≈ 각각 ?
```

자유롭게 합리적으로 구현해도 됨.

### 6. `format_won(amount)` — 원화 표시

```python
format_won(12345)    # → "12,345원"
format_won(1000000)  # → "1,000,000원"
```
